# 💾 Fatimah Aljishi Portfolio

> *A modern portfolio disguised as a Windows 98 desktop.*

This project is a fully interactive portfolio built with **React** and **Vite**, recreating the nostalgic experience of using a classic Windows 98 computer while showcasing my projects, experience, education, and technical skills.

Instead of a traditional scrolling website, visitors can explore the portfolio by opening windows, interacting with desktop icons, playing system sounds, and navigating a familiar retro desktop environment.

---

## ✨ Features

* 🖥️ Fully interactive Windows 98 desktop
* 📂 Draggable desktop icons
* 🪟 Classic Windows-style application windows
* 🔊 Authentic Windows 98 sound effects
* 💼 Projects showcase
* 👩‍💻 Experience and education
* 🛠️ Skills explorer
* 📄 Downloadable CV and certificates
* 📬 Contact form powered by Resend
* 🌐 Responsive layout for modern browsers
* ⚡ Fast loading with Vite

# 🖼️ Windows 98 Experience

The goal of this project wasn't simply to recreate the appearance of Windows 98, but to capture the feeling of using it.

The portfolio includes:

* desktop shortcuts
* classic window chrome
* familiar icons
* retro colour palette
* pixel-inspired UI
* old-school system sounds
* nostalgic interactions

while still using a modern React architecture underneath.

---

# 🎨 Design Philosophy

Most portfolios look the same.

I wanted mine to be something people would remember.

By combining a nostalgic Windows 98 interface with modern frontend technologies, the portfolio reflects both my technical skills and my personality as a developer.

Every interaction was intentionally designed to feel playful while remaining functional and intuitive.
